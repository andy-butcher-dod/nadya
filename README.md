# Nadya: History Practice

A daily practice app for Pearson Edexcel International GCSE History (4HI1):
Russia and the Soviet Union 1905–24, and Dictatorship and conflict in the USSR 1924–53.

Short daily lessons, streaks, and spaced repetition, with Nadya the matryoshka cheering you on.

Install on Android: open the GitHub Pages address in Chrome, tap ⋮ → Install app.
Progress is stored on the device.
